# ⚔️ 2D Sword Fighting Game

A simple 2D sword fighting game built using **HTML, CSS, and JavaScript**.

## 🎮 About the Game

In this game, the player can move, jump, run, and attack an enemy using keyboard controls.
The game uses character animations and basic hit detection to create a simple fighting experience.

## 🕹️ Controls

* A / ←  Move Left
* D / →  Move Right
* W / ↑   Jump
* Space / ↓  Attack
* S / Shift   Run

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

## ✨ Features

* Player movement
* Jump and run animations
* Sword attack animations
* Enemy interaction
* Basic hit detection
* 2D fighting gameplay
